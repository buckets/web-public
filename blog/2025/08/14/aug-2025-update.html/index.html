Aug 2025 Update

Aug 14, 2025 • Matt

Here’s a quick update on the latest with Buckets. It’s been a busy summer and I’m excited to get back to working on fixing bugs, adding features and getting the mobile apps closer to complete.

Code Signing Certificate¶

First, code signing—to make sure the Windows computers know that Buckets is a safe app, Microsoft requires that we add a signature to the app using a certificate we receive from a reliable source. Machines can then verify the signature to ensure Buckets is safe. This explanation is overly simplified, but that’s the gist of it.

Previously, we bought a certificate that worked for three years. But when we went to get a new one, the process and requirements had changed significantly. I’ll spare you the details, but the new process is … not as simple as the old one. Anyway, many frustrating days later, we’ve got a new certificate and can make the app for Windows again!

Swollen batteries on old computers¶

Secondly, we take great pride in keeping Buckets working on old computers. Unfortunately, one of the machines we use to build Buckets for old macOS computers started swelling, indicating that the battery would soon die (thankfully no flames). We’ve replaced that 11-year-old computer with a new one, installed an older operating system and are ready to keep building for old computers.

That said, if you’re on an old mac and the v0.81.0 doesn’t work for you, please let us know.

That’s about it for this update. Back to work!

— Matt
