Buckets 0.80 stable release!

May 15, 2025 • Matt

All the changes made in the past year for the beta version of Buckets have finally landed in the stable version for v0.80.0!

Now everyone can enjoy

  • Payees
  • Dark mode
  • Working bank macros
  • Transaction filtering
  • Mass editing

Next up, we’re going to be working on making sharing between devices simpler and more transparent so it’s obvious how sharing works and easier to figure out what’s broken when it doesn’t work. As part of this work, we’re going to be combining some of the mobile app and desktop app UI code so that the experience sharing between devices is the same whether you’re on the desktop or your phone.

Happy budgeting!

— Matt
